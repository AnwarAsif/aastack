# Playbook: investigate (read-only)
1. Write the question in one line and what answer would change a decision.
2. Gather evidence: files, queries, docs. Samples and aggregates only.
3. Explain every number (skill `explain-number`).
4. Write the answer with sources to docs/research.md. No code or data changes.
5. Report in 10 lines. Hand to `build-ticket` or `fix-bug` if a change follows.
