---
name: prototype
description: Use to answer one design question by running something throwaway (a query, a small script, a UI variant) instead of debating.
disable-model-invocation: true
---

1. State the single question and what result decides it.
2. Build the cheapest thing in `.scratch/`. 3. Run it and record the observed result.
4. Report the answer and a recommendation. Delete the prototype; carry only the decision into the ticket.
